# Defensive Security Examples

Examples in this folder should be benign, authorized, and clearly labeled with prerequisites, effects, expected output, and cleanup. Volume 3's labs use harmless artifacts, synthetic data, or read-only audits. Do not add credential collection, stealth, security-control evasion, malware, or unauthorized persistence content.

The [security review template](../../templates/security-review-template.md) can be used when proposing additions. No examples in this folder should be treated as independently validated against all Windows builds unless tests and their environment are recorded.
