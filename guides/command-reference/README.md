# Command Reference

**Source:** Volume 1, Chapters 4–9 and Chapter 19; Volume 2, Chapter 41; Volume 3, Chapter 55.

The PDFs contain command cards and command indexes; this page helps you navigate them. Consult [the consolidated index](../../docs/command-index.md) for page references.

## How to study a command

- Identify whether it is a CMD built-in or an external executable.
- Read the exact syntax and parameter explanations in the source.
- Determine permissions and side effects before use.
- Test only with disposable sample data where appropriate.
- Record the output and version context; do not treat one system's output as universal.

Do not copy syntax from a PowerShell example into CMD or vice versa without verifying the differences.
