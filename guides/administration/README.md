# Windows Administration and System Health

**Source:** Volume 2, Parts XIV–XVIII; Chapters 35–39 (printed pp. 91–121).

This portion of the source covers Windows Defender Firewall from CMD, event-log architecture and `wevtutil`, Defender administration and investigation, repair tools and boot architecture, and performance measurement and triage.

Prefer read-only inspection and baseline collection before altering protection, recovery, or boot-related settings. Follow the book's caution labels; changes to system/security configuration, boot data, disks, or encryption state can cause data loss.
