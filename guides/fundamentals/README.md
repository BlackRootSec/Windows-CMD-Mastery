# CMD Fundamentals

**Source:** Volume 1, Parts I–II; Chapters 1–9 (printed pp. 9–38).

Start with what CMD.exe is, how it differs from a terminal or shell, how to read the prompt, and how paths, standard streams, exit status, and environment variables work. Then use the command-reference chapters to learn how the book organizes commands.

## Suggested sequence

1. Chapter 1 — Windows, shell, and CMD.exe.
2. Chapter 2 — Anatomy of the prompt.
3. Chapter 3 — Your first commands.
4. Chapters 4–9 — Command cards and command families.

**Practice:** use only information-gathering commands initially. Confirm which interpreter is open and explain each command before running it. See [Getting Started](../../docs/getting-started.md) and [Command Index](../../docs/command-index.md).
