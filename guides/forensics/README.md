# Windows Forensics — Command-Line Collection

**Source:** Volume 3, Part XXIII; Chapters 51–52 (printed pp. 64–77).

The source addresses volatile versus persistent evidence, trusted tools and small footprint, a volatile-evidence collector, interpreting artifacts, validating collection, and a benign simulated incident.

Evidence collection can change the system and may expose sensitive data. Record what was collected, when, by which tool, under whose authority, and with what validation. Avoid claiming that one artifact independently proves a conclusion. Use approved procedures for real incidents and preserve the integrity of original evidence.
