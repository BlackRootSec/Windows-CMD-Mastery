# Windows Filesystem and Permissions

**Source:** Volume 2, Part VII; Chapters 23–24 (printed pp. 21–34).

The source's NTFS chapter covers drives, volumes and paths; NTFS building blocks; attributes; links and reparse points; alternate data streams as a concept; compression, encryption, quotas; SIDs; ACLs; and access decisions. Chapter 24 contains filesystem and permissions command cards.

Before changing permissions or metadata, understand the target path, current access rules, and how to restore the original state. Do not test permission changes on system directories or personal data. See [Lab Safety](../../docs/lab-safety.md).
