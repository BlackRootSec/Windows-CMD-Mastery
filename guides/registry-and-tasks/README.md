# Registry and Scheduled Tasks

**Source:** Volume 2, Parts XI–XII; Chapters 30–31 (printed pp. 63–73). Also see Chapter 29 for identity, tokens, and UAC.

The registry chapter covers root keys/hives, value types, 32-bit and 64-bit views, virtualization, permissions, backup/restore options, and security-relevant locations. The scheduled-task chapter covers Task Scheduler architecture and investigation of a suspicious task.

Registry and task changes can affect system behavior and startup. Start with read-only inspection and use a disposable VM for labs that register, enable, disable, or delete entries. Confirm the exact cleanup procedure before changing state.
