## Before starting

1. Read the lab itself inside the relevant PDF.
2. Check prerequisites and the difficulty legend: `[B]` beginner, `[I]` intermediate, `[A]` advanced, `[X]` expert.
3. Follow the source's SAFETY, DANGER/CAUTION, SECURITY, and NOTE callouts.
4. Run only on an owned or explicitly authorized system, using an isolated VM with a snapshot for state-changing work.
5. Record expected output and follow cleanup instructions.
