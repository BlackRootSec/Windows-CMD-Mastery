# Security Policy

## Scope

This repository is educational documentation for Windows CMD, batch scripting, administration, and defensive security research. It is not an authorization to test third-party systems.

## Reporting a vulnerability in this repository

Please do not publish exploit details, secrets, access tokens, or private data in a public issue. Until a private reporting contact is configured, avoid submitting sensitive operational details and instead report a minimal, non-sensitive description through the repository owner's available private contact channel.

## Responsible content policy

Reports and contributions should focus on safe reproduction, observable evidence, detection, mitigation, and remediation. Do not submit malware, credential theft, stealth, security-control evasion, unauthorized persistence, or access to systems outside the authorized scope.

## Dependency and workflow security

The Markdown validation workflow is intended to run on repository content only. Keep workflows minimal, pin third-party actions if any are introduced, use read-only permissions where possible, and never expose secrets to untrusted pull-request code.
