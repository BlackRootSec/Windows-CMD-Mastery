## Official external documentation portals

Use authoritative documentation for current syntax, versions, and security implications. Follow the relevant command or feature page from these official Microsoft portals:

- [Microsoft Learn](https://learn.microsoft.com/)
- [Windows client documentation](https://learn.microsoft.com/windows/)
- [Windows commands reference](https://learn.microsoft.com/windows-server/administration/windows-commands/windows-commands)
- [Sysinternals](https://learn.microsoft.com/sysinternals/)
- [Windows Security](https://learn.microsoft.com/windows/security/)

These are general portals, not citations for every command listed in the PDFs. Verify each relevant command against the specific documentation page and Windows release before operational use.

## Source-handling principles

- Preserve source terminology, numbering, and safety callouts.
- Mark repository-written pages as supplementary when they go beyond the PDFs.
- Do not silently change command syntax or reconcile disagreements without recording the reason and source.
- Do not claim that examples were executed or independently tested unless that actually happened.
- Confirm rights to redistribute the PDFs before publishing them publicly; see [license status](../LICENSE-STATUS.md).
