## Adding a command entry

When expanding this index, include only details verified against the book or authoritative documentation. Useful fields are command name, purpose, exact syntax, parameters, a harmless example, expected behavior, permission requirements, compatibility notes, safety label, related topics, and source page. Do not merge CMD and PowerShell syntax into a single unlabeled block.
