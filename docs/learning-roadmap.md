# Learning Roadmap

The stages below organize the content of the supplied volumes into a progression. Read in book order on the first pass, as the manuscripts recommend. Page numbers refer to the printed page labels in each PDF.

| Stage | Goal | Source chapters | Completion check |
|---|---|---|---|
| 1. CMD foundations | Understand shell, prompt, paths, streams, exit status, first commands | Volume 1, Chapters 1–3 (pp. 9–16) | Explain your current directory, run basic read-only commands, and describe CMD versus terminal/shell. |
| 2. Command references | Read command cards and group commands by purpose | Volume 1, Chapters 4–9 (pp. 19–38) | Find a command's purpose, syntax, and constraints in the source index. |
| 3. Parser and edge cases | Understand expansion, operators, redirection, pipes, lookup, quoting | Volume 1, Chapters 10–13 (pp. 41–63) | Explain why parsing and quoting matter without guessing at unusual edge cases. |
| 4. Batch scripting | Work with variables, arguments, control flow, subroutines, errors, logging, testing | Volume 1, Chapters 14–16 (pp. 66–79) | Write and test a harmless script with argument checks and a clear exit status. |
| 5. Filesystem and processes | Understand NTFS, permissions, processes, and investigation | Volume 2, Chapters 23–26 (pp. 21–44) | Identify which commands inspect state and which alter it. |
| 6. Services and configuration | Learn services, identity/tokens, registry, scheduled tasks | Volume 2, Chapters 27–31 (pp. 47–73) | Describe the purpose and risks of each area before running any modifying procedure. |
| 7. Networking | Learn networking fundamentals, command cards, troubleshooting decision trees | Volume 2, Chapters 32–34 (pp. 76–87) | Follow a bottom-up diagnostic sequence and record the observed evidence. |
| 8. Protection and health | Review firewall, event logging, Defender, repair/recovery, performance | Volume 2, Chapters 35–39 (pp. 91–121) | Build a read-only status summary before proposing configuration changes. |
| 9. Defensive research | Interpret telemetry, evaluate suspicious behavior, prevent batch injection, harden command resolution | Volume 3, Chapters 44–49 (pp. 8–56) | Describe observed evidence, likely benign explanations, mitigations, and uncertainties. |
| 10. IR and forensics | Scope an incident, preserve evidence, validate collection, report findings | Volume 3, Chapters 50–52 (pp. 59–77) | Produce a report with scope, timeline, artifacts, actions, limitations, and cleanup/hand-off notes. |

## How to use the lab sets

- Volume 1 lists labs **1–25** and **41–65**.
- Volume 2 lists labs **26–40**, **66–70**, **81–112**, and **151–165**.
- Volume 3 lists labs **71–80** and **116–150**.

Use [the lab index](../labs/README.md) for the source's stated ranges. Complete only labs whose prerequisites you understand, and always follow the specific cleanup step. Completion of this roadmap is learning practice, not a certification or guarantee of professional proficiency.
