# Frequently Asked Questions

### Is this repository for CMD or PowerShell?
It is centered on Windows Command Prompt (`cmd.exe`) and batch files. They are not interchangeable with PowerShell; label any PowerShell examples explicitly.

### Where should I start?
Start with [Volume 1](../books/Windows_CMD_Mastery_Volume1.pdf) and the [learning roadmap](learning-roadmap.md).

### Are individual labs documented separately here?
Not yet. The [lab index](../labs/README.md) preserves the source's lab ranges and chapter locations without inventing individual objectives that have not been extracted.

### Can I run everything on my everyday Windows installation?
No. Some source labs can change system configuration or security state. Follow each lab's safety instructions and use an isolated VM with a snapshot when needed.

### Why is there no LICENSE file?
The supplied manuscripts state “All rights reserved.” See [LICENSE-STATUS.md](../LICENSE-STATUS.md). Confirm your rights and select an appropriate license before publicly redistributing source material.
