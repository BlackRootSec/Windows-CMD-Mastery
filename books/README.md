## Suggested reading order

1. Volume 1, in order, to build command-line and batch fundamentals.
2. Volume 2, in order, to learn administration and troubleshooting.
3. Volume 3, in order, for defensive research, incident response, and forensics.

Use each book's own “How to Use This Book” section and obey its lab-specific prerequisites, expected results, and cleanup steps.
